# AI & RAG Service (AI-Powered Enterprise Knowledge Assistant)

Independent AI Microservice providing Retrieval-Augmented Generation (RAG), semantic vector embedding search, and grounded knowledge synthesis for the Enterprise Knowledge Assistant.

## Architectural Overview
- **Polyrepo & Microservices**: Independently deployable, scalable microservice.
- **Port**: `8083` (routed via API Gateway `8080`).
- **Database**: Dedicated PostgreSQL database (`knowledge_vector_db`) with vector embedding storage.
- **Service Discovery**: Netflix Eureka Client registered with `discovery-server` (`8761`).
- **RAG Architecture**:
  - Ingests text chunks generated by `document-service`.
  - Converts text chunks into normalized dense semantic vector embeddings.
  - Performs cosine similarity matching against stored knowledge embeddings with customizable similarity thresholds and top-K limits.
  - Synthesizes grounded AI answers accompanied by precise document chunk citations.

## Tech Stack
- **Java**: 21
- **Framework**: Spring Boot 3.3.5
- **Cloud Ecosystem**: Spring Cloud 2023.0.3 (Netflix Eureka Client)
- **Persistence**: Spring Data JPA / Hibernate, PostgreSQL
- **Monitoring**: Spring Boot Actuator
- **Testing**: JUnit 5, Mockito, H2 In-Memory Database

## Environment Variables
The application uses externalized configuration loaded from `.env` or system environment variables:

| Variable | Description | Default |
|---|---|---|
| `SERVER_PORT` | HTTP Server Port | `8083` |
| `SPRING_APPLICATION_NAME` | Eureka Application Name | `ai-service` |
| `DB_HOST` | PostgreSQL Host | `localhost` |
| `DB_PORT` | PostgreSQL Port | `5432` |
| `DB_NAME` | Service Database | `knowledge_vector_db` |
| `DB_USERNAME` | Database User | `postgres` |
| `DB_PASSWORD` | Database Password | `postgres` |
| `EUREKA_SERVER_URL` | Eureka Service Registry URL | `http://localhost:8761/eureka/` |

## Setup & Running

### 1. Configure Environment
Copy `.env.example` to `.env` and set appropriate database credentials:
```bash
cp .env.example .env
```

### 2. Build and Test
```bash
mvn clean package
```

### 3. Run Service
```bash
mvn spring-boot:run
```

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/v1/ai/ingest` | Ingest and store vector embedding for a document chunk |
| `POST` | `/api/v1/ai/search` | Search top-K similar chunks using cosine similarity |
| `POST` | `/api/v1/ai/query` | RAG query returning grounded answer + citations |
| `GET` | `/actuator/health` | Health check endpoint |
| `GET` | `/actuator/info` | Application info endpoint |
